# Brain Tumor Studio

برنامه‌ی دسکتاپ برای پیدا کردن تومور مغزی در تصاویر MRI با هوش مصنوعی (مدل U-Net).

تصویر را وارد می‌کنید، برنامه ناحیه‌ی مشکوک را روی آن نشان می‌دهد. می‌توانید دیتاست و مدل خودتان را هم معرفی کنید و مدل جدید آموزش بدهید.

> ⚠️ این برنامه فقط برای پژوهش و آموزش است و جایگزین تشخیص پزشکی نیست.

## برنامه چه کارهایی می‌کند؟

- **پیش‌بینی:** تصویر (یا چند تصویر یا یک پوشه) را بدهید تا تومور مشخص شود. نتیجه را می‌توانید به‌صورت عکس ذخیره کنید.
- **دیتاست:** پوشه‌ی عکس‌ها و پوشه‌ی ماسک‌ها را نشان بدهید. برنامه خودش بررسی می‌کند که همه‌چیز درست است.
- **مدل‌ها:** مدل خودتان (فایل `.h5` یا `.keras`) را اضافه و فعال کنید.
- **آموزش:** مدل تازه آموزش بدهید و پیشرفتش را روی نمودار ببینید.

برنامه فارسی و انگلیسی است و تم تاریک و روشن دارد.

## نصب

به این‌ها نیاز دارید:

1. [Node.js](https://nodejs.org) (نسخه‌ی ۱۸ یا بالاتر)
2. [Python](https://www.python.org/downloads/) (نسخه‌ی ۳.۹ تا ۳.۱۳)

بعد در ترمینال:

```bash
git clone https://github.com/<you>/brain-tumor-studio.git
cd brain-tumor-studio
npm install
npm start
```

بار اول که برنامه باز شد، اگر کتابخانه‌های پایتون نصب نبودند، یک صفحه نشان می‌دهد. روی **«نصب خودکار وابستگی‌ها»** بزنید و صبر کنید (چند صد مگابایت دانلود می‌شود). بقیه‌اش خودکار است.

## نحوه‌ی استفاده

### ۱. پیش‌بینی با مدل آماده
برنامه با یک مدل پیش‌فرض می‌آید. به صفحه‌ی **پیش‌بینی** بروید، عکس MRI را بکشید و رها کنید (یا دکمه‌ی «افزودن تصویر» را بزنید). با اسلایدر «آستانه‌ی تشخیص» می‌توانید حساسیت را کم و زیاد کنید.

### ۲. آموزش مدل با دیتاست خودتان

1. به صفحه‌ی **دیتاست** بروید، پوشه‌ی عکس‌ها و پوشه‌ی ماسک‌ها را انتخاب کنید و «بررسی دیتاست» را بزنید.
2. به صفحه‌ی **آموزش** بروید. برای شروع همان تنظیمات پیش‌فرض (معماری «سبک») خوب است.
3. «شروع آموزش» را بزنید. وقتی تمام شد، بهترین مدل خودکار ذخیره و فعال می‌شود و می‌توانید در صفحه‌ی پیش‌بینی ازش استفاده کنید.

### ۳. استفاده از مدلی که از قبل دارید
در صفحه‌ی **مدل‌ها** روی «افزودن مدل» بزنید و فایل `.h5` یا `.keras` را انتخاب کنید.

## دیتاست را چطور آماده کنم؟

برای هر عکس یک ماسک لازم است (عکس سیاه‌وسفیدی که جای تومور در آن سفید است). یکی از این حالت‌ها کافی است:

- دو پوشه با نام فایل یکسان: `images/a.png` و `masks/a.png`
- یک پوشه، با پسوند `_mask` برای ماسک: `a.tif` و `a_mask.tif`
- زیرپوشه‌ها هم مشکلی ندارند

فرمت‌های مجاز: PNG، JPG، BMP، TIFF، WebP.

## نکته‌های آموزش

- با معماری **سبک** و ۱۰ تا ۲۰ اپوک شروع کنید تا مطمئن شوید همه‌چیز درست کار می‌کند.
- عدد مهم **Dice** است؛ هرچه به ۱ نزدیک‌تر باشد، بهتر است.
- روی CPU آموزش کند است. اگر کارت گرافیک دارید، TensorFlow مناسب GPU نصب کنید.

## مشکل دارید؟

- **«موتور پایتون آماده نیست»:** دکمه‌ی نصب خودکار را بزنید. اگر نشد، مطمئن شوید پایتون نصب است.
- **مدل لود نمی‌شود:** فایل باید مدل Keras با پسوند `.h5` یا `.keras` باشد.
- **نتیجه‌ی پیش‌بینی بی‌معنی است:** مدل باید با همین نوع تصویر آموزش دیده باشد.
